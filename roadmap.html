ROADMAP

UPDATED 2026-08-19 · v1.9.0

//SHIPPED

Vault & editor
File explorer, markdown editor on CodeMirror 6, atomic writes, external-edit conflict detection.
Terminal
Real zsh tabs rooted at the vault, with splits.
Theming
Three-layer themes, tweakcn import, per-slot font and color overrides.
Tasks
Kanban, filterable table and "my day" — over type: task files.
Links
Wikilinks with autocomplete and backlinks, properties panel, live preview, rename-updates-links.
Workspace
Nested splits, tab drag & drop, layout remembered per vault.
Quick switcher
Cmd+P by name and title, Cmd+Shift+F full-text.
Integrated titlebar
Obsidian-style chrome, collapsible sidebar.
WYSIWYG tables
Markdown tables edited in place, with row and column drag.
Code editor
Non-markdown files with syntax highlight and line numbers.
HTML preview
Source ↔ rendered toggle for .html.
MCP server
The app exposes tools that let an agent drive its own UI.
Packaging & self-update
Ad-hoc signed .dmg, and an updater that swaps the bundle without a reinstall.
Tab gestures
Tabs shrink to fit the strip instead of scrolling out of reach, and middle-click closes one.
Explorer menu
Create a note or folder inside the one you right-clicked, an icon per file type, a color per item, plus copy path and reveal in Finder.
Pane navigation
Back and forward through the notes you visited in that pane, and a breadcrumb whose folders open the explorer to them.
Inline title
The document's name as a big editable title — editing it rewrites the frontmatter or renames the file, updating wikilinks either way.
Status bar
Words, characters, properties and backlinks for the focused note, in a strip that stays put when focus moves elsewhere.
The document column
Line numbers that respect the theme and sit in the margin, and text that never touches the edge of a narrow pane.
The tab strip
Tabs you can actually hit, each with an icon saying what is inside it. Right-click one for the same menu the file tree gives you. A + that opens a note or a terminal beside or below. Named terminals that come back in the folder they were in. And tabs that stop shrinking at icon width — whatever no longer fits moves into a menu instead of off the edge.
Tasks without a modal
Complete a task from its card, mark one blocked with a reason, and fix its text in place — in the board, the table and "my day" alike. Open the whole document in a panel beside the board instead of on top of it, and leaving a task saves it.
Find in the document
Cmd+F inside a note — in reading mode too — with a counter, case, whole-word and regexp toggles, and replace behind a disclosure. Alongside it: pick a property's type as you create it, type #tag while creating a task and have it land as a tag, and closing a pane finally hands its space back to every pane, not just its neighbours. Losing the window's focus no longer cancels a rename in progress — or, on a task card, silently commits one.
Nothing gets lost
Obsidian-style autosave — what you type reaches disk on its own, with a toggle that hands the old Save/Discard flow back. The tab dot now means "this is not on disk", which under autosave means a conflict and nothing else. Alongside it, three ways the app used to write over you: a blur caused by the window losing focus no longer renames a file or creates one, a custom table column no longer flattens a list, a number or a map into a string, and a YAML comment written inside a list survives the edit.
Closing the day
Git inside the app, with vault backup as the point: one click stages, commits and pushes, and reports which of the three steps stopped. A branch and change count in the status bar, staging and diffs per file, the last commits with the GitHub PR clickable, branch switching that closes tabs for files the other branch doesn't have — and merge conflicts resolved block by block, in an editor that stopped deforming the conflict markers three different ways.
A document that starts written
Templates are plain .md files in a visible folder, so a template looks like the file it produces: placeholders for the title, the date in any format and where the cursor lands, merged into an existing note without ever overwriting a key it already has. Quick actions are .md files too, and the body is the prompt — one click spawns your agent CLI in a terminal tab with the prompt handed over in argv position, never through the shell. Pinned actions live in a ribbon down the left, and every action is also reachable from Cmd+P.
The frame
The three surfaces around the document, and none of them writes to your vault. Cmd+R stops reloading the window when there is no preview to refresh — a reload took every running terminal with it, Claude Code included — and main-frame navigation is refused outright, which closes the same hole a file dragged in from the Finder used to open. The active tab floats: four rounded corners, breathing room on both axes, and the gap between tabs is the separator. And a long filename in a deep folder is readable again — the tree scrolls sideways, with the row highlight following it to the end of the name.

//LATER

More than one vault
Two vaults open side by side, in their own windows.
Somewhere to call it from
A command registry, so everything the app can do is reachable by keyboard or from the switcher — including the board, the table and "my day", a scratchpad a keystroke away, and a settings tab where those keys can be changed.
One grammar
The same markdown typed anywhere gives the same result: #tag when renaming a task, not only when creating one, and links inside a table cell.
The task's own state
Done stops meaning "moved column": a task gets state of its own, the board becomes one view of it, and "my day" can be added to and reordered by hand.
Make it yours
A theme editor inside the app instead of pasted CSS, and a colour and icon per terminal tab.
