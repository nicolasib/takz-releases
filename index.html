// 01 TASKS

A task is a file.

type: task in the frontmatter, plus status, due, tags and whatever custom fields you invent. Drag a card across the Kanban and what changes is the file's frontmatter. Kanban, a filterable table and a 'my day' view, all reading the same files.

// 02 NOTES

Markdown, live.

A live-preview editor on CodeMirror 6. [[wikilinks]] with autocomplete and backlinks, frontmatter as an editable properties panel, tables you edit in place, and a file explorer over the whole vault.

// 03 TERMINAL

A real shell, in a tab.

zsh, as many tabs as you want, rooted at your vault. Built for one thing above all: running Claude Code beside the notes it's writing about.

Features

SPLITS & TAB DRAG

Split any pane, nest them, drag tabs between them. The layout is remembered per vault.

THEMES

Three-layer theming. Import any tweakcn theme, then override colors, radius and four font slots.

QUICK SWITCHER

Cmd+P across names, titles and aliases. Cmd+Shift+F for full-text with snippets.

CODE EDITOR

Open .ts, .py, .json, .css with syntax highlight, line numbers and find & replace.

HTML PREVIEW

Toggle any .html between source and rendered page. Cmd+R to refresh.

MCP SERVER

takz exposes its own MCP server. Claude Code, in the terminal tab, can open files, create notes and move Kanban cards — in the window you are looking at.

EXTERNAL EDITS

Obsidian or an agent can rewrite the vault under you. takz notices, and never silently overwrites your unsaved buffer.

ATOMIC WRITES

Unknown frontmatter fields, formatting and syntax the app did not author survive every single write.

//THE HONEST PART

takz is signed ad-hoc, not with an Apple Developer ID, and it is not notarized. The first time you open it, macOS will refuse. This is the whole workaround, and you only do it once:

xattr -dr com.apple.quarantine /Applications/takz.app

Or: System Settings → Privacy & Security → Open Anyway. Once is all it takes — the updates the app installs for itself are never quarantined, so this never comes back.

//IT UPDATES ITSELF

takz checks a static JSON feed on launch and every six hours. When a new version exists it downloads in the background and verifies its SHA-256 — and then it waits. It never restarts on its own: you click Restart to update when your terminals are done. If anything goes wrong mid-swap, the previous app is put back.
